1
#役割
誰として答えるか。専門家を指定すると語彙と観点が変わる。
2
#命令
やってほしいことを一文で。ここだけ書くのが「ふつうの使い方」。
3
#文脈
自社の状況。ここを書くと一般論が自分ごとの答えになる。
4
#制約事項
やってほしくないことを先に潰す。やり直しがいちばん減るのはここ。
5
#出力指示
形式と数。「3製品」と書かないと数が揃いません。

全部書く必要はありません。うまくいかないときに、足りない見出しを1つ足す。それだけで直ります。

{{ }} を全部埋める
埋め残すと、AIがその部分を創作します。使わない項目は行ごと消す。
2
「ないものは書かない」を必ず入れる
「資料に記載がない場合は『記載なし』とだけ答える」。この一行の有無で、返ってくるものの信頼度が変わります。
3
評価と修正を1ターンにしない
まず指摘だけ出させ、採用する指摘を選んでから直させる。同時にやると、主張ごと書き換えられます。

社内データを参照する型は、使う道具が社内に接続されている場合にのみ動きます。接続がない道具では、資料を自分で貼って使ってください（10 を参照）。

営業

1. 商談前ブリーフ ─ 事実を調べさせず、調べる項目を作らせる
明日の商談に向けたブリーフを作成してください。 #相手企業（私が確認済みの情報のみ） - 業種 / 規模 / 地域：{{ }} - 面談相手の部署・役職：{{ }} - 公開情報から分かっていること：{{無ければ「未確認」}} - これまでの接触：{{資料DL、過去商談の要点}} #出力 1. 確認済み事実の整理（ここに新しい事実を足さない） 2. 業界一般の仮説5つ。各々に「商談で確かめる質問」を1つ 3. 要確認リスト（調べ方とセットで最大5つ） 4. 地雷（言うと印象を損ねる可能性のある発言3つ） #制約 - 「確認済み事実」に無い企業固有の事実（数値・取り組み名・ 人名）を一切生成しない。仮説は断定形を使わない
2. 文面の自己改良ループ
以下の営業メールを自己評価し、改訂版を出してください。 #手順（この順で必ず出力） 1. 5観点×20点で採点（件名／冒頭2行／提供価値／ 証拠／CTA）と減点理由 2. 減点の大きい3点を、直し方とセットで 3. 改訂版。文字数は元の文面以下に収めること 4. 再採点。95点以上を付けるなら、それでも残る 減点候補を必ず1つ挙げる #制約 - 敬語を増やして丁寧にするだけの修正は改善とみなさない - 元の文面にない実績・数値・顧客名を追加しない
Note ─ 提案書骨子

7章立て＋自己採点100点ループ。第1章「現状認識」をヒアリング発言の引用だけで書けないなら、 作り直すのは提案書ではなく商談です。

05Marketing

マーケティング・企画

1. ファクトチェック ─ 必ず別チャットで実行する
あなたはファクトチェッカーです。以下を検証対象として扱い、 内容を擁護せず批判的に点検してください。 #依頼 1. 「事実主張」だけを抽出し番号付きリストに。事実主張とは 数値・固有名詞・年次・順位・因果関係を含む検証可能な文。 意見・推奨・一般論は除外 2. 各主張を表に。列は 主張 / 検証に必要な一次情報 / 確認先 / 判定（検証可能・出典不明・検証不能）/ 誤っていた場合の事業判断への影響（大中小） 3. 「出典不明 かつ 影響大」を優先度順に並べ、検証するまで 意思決定に使ってはいけない旨を明記 4. 調査会社レポート名・統計名は実在の自信度を添え、 中以下は捏造の可能性が高いと警告 #制約 - 「概ね正しいと思われます」のような曖昧な判定は禁止 - 検証していないものを「正しい」と判定しない
2. 競合比較表と空白地帯の特定
この市場の競合を「直接競合3社」「間接競合2社」 「代替手段2つ」に分けて挙げ、表にして。 列は 区分 / 名称 / 提供価値 / 主なターゲット / 価格帯 / 強み / 弱み・未対応領域 / 数値情報の確度 #制約 - 「弱み」は【構造的な制約】か【単なる未着手】かを 区別して書く。狙うべきは前者 - 売上・シェア等の数値は出典を併記。特定できない 場合は「非公開」と書く。推測値を書かない - 「代替手段：何もしない」を必ず含める
Caution

競合の売上・シェア・ユーザー数は捏造率が高い。企業名と提供内容までは使えますが、数値はIR資料等で必ず確認してください。

1. 属性の除去 ─ 漏えい対策ではなく、公正な選考のため
#命令 以下のテキストから、選考評価・分析に不要な個人識別情報を除去し、匿名化版を出力してください。 #除去・置換ルール - 氏名 → 「{{候補者ID}}」に置換（読み仮名・ローマ字も） - 生年月日・年齢／性別を示す記述／住所 → 削除 - 連絡先・SNS・個人URL／顔写真への言及 → 削除 - 国籍・本籍・出身地・出身校名 → 削除（学部・専攻は残す） - 家族構成・扶養／傷病・障害・妊娠出産・育児介護 → 削除 - 在籍企業名 → 「A社（業界／従業員規模）」に一般化 - 業務内容・実績数値・使用ツール・保有資格 → そのまま残す #出力指示 1. 匿名化済みテキスト 2. 除去した項目の一覧（項目名のみ。値そのものは出力しない） 3. 判断に迷い、要確認の箇所
2. バイアス自己監査 ─ 四半期に一度
以下の「評価出力」を検査し、JDに記載のない評価軸や、 属性に基づく推測が混入していないか指摘して。 #検査観点 1. JDの必須・歓迎要件にない評価軸が使われていないか 2. 性別・年齢・国籍・出身校・家族構成・傷病等への言及や推測 3. 就業の空白期間そのものを不利に扱っていないか 4. 経歴の「書き方の巧拙」を能力と混同していないか 5. 「記載なし」と「経験なし」を混同していないか #出力指示 該当箇所（原文引用）/ 観点番号 / なぜ問題か / 修正案 の表。問題が無ければ「指摘なし」と明記
Check

氏名だけを変えた同一経歴を2〜3パターン流し、出力が変わらないことも確認する。

07People & Managers

人事・組織／管理職

1. サーベイ自由記述の分析 ─ カテゴリを先に決めない
#手順 1. 回答を読み、内容に基づいてカテゴリを抽出する （カテゴリは事前に指定せず、記述から立ち上げる） 2. 各カテゴリの件数を集計し、要旨を示す（原文を引用せず、 複数人に共通する内容を言い換えて記述） 3. 件数が2件以下は「少数意見」として別枠に全件列挙する （要約や統合をしない） 4. 「深刻度（高中低）×件数」で整理 5. この分析からは判断できない事項を列挙 #制約事項 - 原文に書かれていない原因・背景を推測しない - 個人が特定される記述は要旨に含めない - ハラスメント・差別・違法行為・安全上の危険を示唆する 記述は集計に混ぜず、件数のみ冒頭に出し、内容は 記載せず規定の窓口へ連携が必要と明記する
2. 1on1の論点整理 ─ 評価はさせない
あなたは1on1の準備を支援するアシスタントです。 評価や人事判断は行いません。 #出力指示 1. 前回からの差分（進んだ／止まっている／新しく出た） 2. 前回合意したアクションの状況と、障害 3. 今回話すべき論点（3つまで。優先順と理由） 4. 論点ごとの問いかけ案（各2つ。詰問にならない言い回し） 5. 今回は扱わないほうがよい話題と、その理由 #制約事項 - 本人の記述に無い内容を推測で補わない - 性格・資質・適性を評価しない。行動と成果物に限定 - 論点は「本人が次の2週間で動かせるもの」に絞る

1. 参照資料限定Q&A ─ 嘘をつかせたくない場面の基本形
#命令 以下の「参照資料」のみに基づいて、私の質問に回答して ください。 #参照資料 {{規程・ガイドライン・仕様書を貼る}} #回答の絶対ルール - 参照資料に書かれている内容のみを根拠とすること。 一般常識・他社事例・推測で補わないこと - 回答には必ず、根拠となる箇所を原文のまま引用すること - 記載が無い場合は「参照資料に記載なし」とだけ回答する - 記述が曖昧または矛盾している場合は指摘し、どう解釈 しうるかを両論併記する #出力形式 【回答】結論を2文以内 【根拠】資料からの引用（「」で囲む） 【備考】解釈の余地・確認が必要な点。無ければ「なし」
2. リライト・添削 ─ 必ず2ターンに分ける
【ターン1｜指摘のみ】 以下の文書をレビューし、修正はせずに問題点だけを 列挙してください。読み手は{{ }}、目的は{{ }}。 出力は4列の表のみ：No / 該当箇所（原文引用）/ 問題の種類 / 修正方針 種類は「事実の不明瞭さ／論理の飛躍／冗長／語調の 不一致／体裁」で分類。重要度順、最大10件。 【ターン2｜採用分のみ反映】 上記のうち No.{{ }} のみを反映して全文書き直して。 指摘していない箇所は原文のまま。元の主張・結論を 変えない。数値・固有名詞・日付は一切変更しない。

10What remains

契約で消えるリスクと、消えないリスク

場面法人契約で下がるリスクそれでも人がやること
履歴書・職務経歴書学習利用と外部流出は契約で対処済み評価に不要な属性は除去する。理由は漏えいではなく公正な選考。本籍・家族・傷病等は、人が読む場合も把握してはならない事項（06）
書類選考・面接評価契約とは無関係判定をそのまま合否に使わない。氏名だけ変えた同一経歴で出力が変わらないかを定期確認する（06）
1on1・面談保存先は契約テナント内生の会話記録は本人の同意を取る。健康・家庭事情は入力しない。漏えいではなく目的外利用の問題（07）
サーベイ自由記述契約とは無関係ハラスメント・違法行為・自傷の示唆は集計に混ぜず、規定の窓口へ即エスカレーション（07）
参照する情報の範囲権限に基づく参照は道具側が担保貼る側の道具には何でも持ち込めます。閲覧権限のない資料を、自分で持ち込まない
調査・市場データ契約とは無関係統計名や数値の捏造は契約では防げない。別セッションでファクトチェックし、一次情報に当たる（05）

法人契約で消えるのは漏えいのリスクだけです。誤った判断と目的外利用は消えません。会話ログは管理者が閲覧・エクスポートできるため、人事・法務の機微情報は閲覧範囲を確認してから入れてください。
